# 项目设计依据与审核交接

生成与审核使用同一份设计依据和批准范围。本约定是现有 Apply 的输入补充，不新增阶段或 Apply 内的设计系统建设任务。Init 可经用户确认建立项目设计基准，但未初始化的项目不因此被阻塞。

## 先找依据，再做增量

- 先读项目约定及用户指定入口（如 DESIGN.md）；无指定时检查已有正式入口及默认 pmspec/design/DESIGN.md，多个冲突先澄清，不另建副本。按入口链接只读通用规范、本需求涉及的组件/页面模式与品牌规则，只提取本次涉及的组件、页面骨架和状态；需要时再读其引用的组件说明、历史原型、截图或代码。不强制提供代码仓、tokens 或特定目录结构。
- 依据顺序：用户本次指定 → 项目明确认可的规范或历史原型 → 内置默认主题。记录来源位置、版本标识（适用时）及适用页面；不能凭版本号最大或修改时间最新认定已批准。外部代码固定到实际分支/commit，标清线上、测试或计划属性。
- 已有项目缺规范时，先复用可核对的历史组件和布局，说明缺口；仅当缺口影响本次判断时澄清。不自动创建 DESIGN 或庞大文档树；新项目无依据时可直接使用内置默认主题，读取 [默认设计依据](default-design.md) 与实际 CSS；这不代表品牌设计或移动端能力已就绪。
- 简述本次新增 / 修改 / 保留项，以及关键组件与页面骨架的来源、变体和对应原型位置。保留无关操作、入口顺序与布局，不把局部改动扩大成整页重设计。信息可放在需求目录外运行临时区的交审说明中，不另建强制台账；正式规则自包含于 proposal 或旁注。过程材料按[交付清理约定](delivery.md)留痕后清理。
- 自包含 HTML 可保真映射生产组件，无需搬入框架或新增依赖。不能只复用色值却重画按钮、关闭控件或页面结构；也不因类名不同就判未复用。

Init 提取的“已观察”或“待确认建议”不是已批准项目规则，不能因文件存在而自动采用或作为审核扣分依据；核对 DESIGN 记录的来源版本与采用状态。本需求明确获准使用草稿时按其批准范围执行，不要求额外全局批准；未采用草稿也不应抹掉可核对的既有组件事实。缺口需默认补齐时确认相应采用范围，不静默覆盖项目规则。

## 批准按范围生效

允许提取规范、本需求采用该规范、全项目迁移是不同授权。记录用户批准来源与范围；用户已明确让本需求采用某草稿基准时，不再因它未全局批准而重复阻塞。仅遇到新冲突、影响需求/权限/验收的未知或超出批准范围时再确认，其他部分继续。

## 评审层与产品层

索引、评审状态切换、旁注属于评审层；外壳内的产品组件服从本次设计依据，内置产品主题只是兜底。复制模板后，在注入标记外用产品根容器作用域隔离或覆盖默认产品样式；核对全局选择器、变量继承及后置规则，避免影响评审层或覆盖项目组件。不要把产品中不存在的状态横条、重复工具栏塞入画面，不为此改套件公共资产。

## 维护边界

不在 Apply 中自动创建/更新项目设计系统或复制品牌资产，只提出沉淀建议。已有 token/组件文档优先引用；项目快照不宣称实时同步。必需素材按许可安全内嵌，保留声明；无资产不虚构正式 LOGO、不打包未获授权的字体。

## 精简交审输入

主 Agent 产出、实测并修订；独立 prototype-review 只读审核、复审。一次交接包含：

| 输入 | 内容 |
|---|---|
| 目标与需求 | HTML、proposal（示例则为示例说明）、本次变更范围及批准来源；遵从项目指定需求根目录，否则用默认路径 |
| 设计依据 | 设计入口与本次读取的通用/组件/模式/资产文件、来源版本、采用状态及本次批准范围；无项目依据则写“无，采用内置默认主题”，注明默认来源版本 |
| 复用边界 | 新增/修改/保留项，关键组件变体与页面骨架到原型位置的映射 |
| 审核规则 | 当前 apply 技能绝对路径，供读取套件审核定义与共享清单 |
| 当前证据 | 被检文件版本标识（如哈希）、浏览器/视口、已测步骤与结果、截图或记录位置、Not run；视觉改动附受影响关键控件的最终生效样式样本 |

临时证据可从需求目录外读取，不要求复制进 prototypes/；审核完成后先在宿主持久任务记录留痕，再按[交付清理约定](delivery.md)处置。审核未完成时保留必需证据。

证据应与当前产物对应，不规定断言数量、固定视口数量或全量样式矩阵。修订后复测受影响项，更新版本标识并提交复审；未改部分可引用明确标注适用版本的证据。真实 APP 或后端未运行，不自动阻塞纯原型范围内的审核；原型自身缺必需浏览器证据或独立审核则仍只能交草稿。

审核报告列出实际读取的需求/设计依据、适用批准范围、套件审核定义与清单，以及证据版本。分别判断组件变体复用、页面骨架、最终生效样式，不以源码 token 存在代替实际样式证据。独立审核结论必须取回后才能交付，主 Agent 不得换角色自判通过。
