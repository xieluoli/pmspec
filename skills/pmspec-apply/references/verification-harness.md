# 验证脚手架

复用宿主已有浏览器，不安装 Playwright、浏览器服务或 npm 包。脚本只是启动与取证脚手架，不替代产品用例、独立审核和人工验收。

## 预览与读取

先从需求目录外运行区启动 `node "<APPLY_DIR>/scripts/preview.mjs" "<HTML>"`，保存返回的 URL、sha256、pid。默认随机空闲端口，固定 127.0.0.1，不暴露其他文件或目录。内容为启动时字节快照，修订后关闭旧服务并重新启动。固定端口被占用须报错，不接管已有进程。使用宿主提供的进程生命周期管理，完成后关闭本次精确句柄，不按程序名杀进程。

源码定位用 `node "<APPLY_DIR>/scripts/inspect-html.mjs" "<HTML>" "<定位文本>"`，只省略 base64 数据，原行号与原字节 SHA256 保留。输出不能覆盖原 HTML，原图需另行视觉核对。

## 宿主浏览器调用

[browser-checks.js](../scripts/browser-checks.js) 是函数表达式，不是模块。宿主读取文本后，以现有浏览器执行工具传入真实 `page`，如 `(<函数表达式>)(page, <本轮配置>)`；不得把占位符当代码。文件读取和结果保存由外层宿主工具负责，不在浏览器服务器中尝试 require/import。没有文件执行接口就粘贴函数，不绕过权限或新起另一宿主 CLI。

配置字段：

| 字段 | 含义 |
|---|---|
| url / sha256 | 使用本次 preview 返回值，响应头须与快照哈希相符 |
| viewport | 本例视口，默认 1440×1080；项目有标准时采用项目值，多个视口分别运行 |
| cases | `[{name, run: async (page, check) => {...}}]`，独立的受影响用例与关键路径冒烟 |
| reset | `async page => {...}`，每次重新导航后执行；恢复当前原型的权限、模拟结果等前置状态，不发真实业务请求 |
| capture | `async (page, name) => <截图位置或 null>`；仅使用当前宿主已验证支持的截图接口，路径在需求目录外；无此能力如实列缺口 |

测试使用稳定 section ID、data 属性或语义定位器；禁用/隐藏状态直接断言，不点击。每例前重新导航，清除上一例 DOM、内存、定时器；localStorage/IndexedDB 等持久数据及 cookie **不会自动清除**，由项目专用 reset 在已确认的测试页/测试上下文内恢复，不能清空共享浏览器的其他站点状态。只需清除本页演示数据时在 reset 中操作对应键，再重载并验证；不对未知页面通配清理。

脚本总是返回 JSON 兼容的对象：版本、浏览器/视口、逐项结果、控制台/网络异常、截图引用、Not run 与 passed；用例失败也返回证据并继续其余独立用例，finally 移除自己注册的监听。外层必须核对 passed，不能把工具执行成功当检查通过。无产品用例只代表通用冒烟，Not run 明示。

通用检查只涵盖唯一 ID、索引锚点、整页横向溢出与运行异常；产品主流程、子 Tab、返回、失败恢复、局部遮挡及最终生效样式须由 cases 显式补足。有意的模拟错误要在业务断言中核对；控制台真实异常不能静默过滤成成功。

## 保存证据而非反复摸索

先用一个小用例验证宿主能返回完整结构化结果和截图位置，再复用这一路径。宿主把结果写文件时直接保存其输出；否则由外层文件工具把返回 JSON 原样落盘，不以手工摘要代替原始记录。保存当前产物哈希及证据文件哈希，失败也留痕；截图缺失不得伪称已拍。记录 Not run（包括未实测的 file/离线或其他宿主）及原因。

交审及基线引用遵循 [增量验证与交审](incremental-review.md)。产物字节未变可重复运行同一快照；修订后的旧证据仅能按可核验基线引用，不能贴新哈希冒充重测。过程文件不进入正式需求目录。
