# 项目设计系统 · 入口模板

供 Init 填写，不原样交付。默认输出 pmspec/design/DESIGN.md；已有正式入口则沿用。正文只保留实际项目内容和有效相对链接。

## 适用范围

产品、网页/桌面/移动端、支持的主题、适用页面；不支持项如实说明。

## 来源与采用状态

| 项目 | 内容 |
|---|---|
| 来源 | 已认可文档 / 仓库标识、分支、commit、相关工作区修改 / PMSpec 默认版本 |
| 来源属性 | 已上线证据 / 测试实现 / 计划 / 未核实；不由分支名推断 |
| 采用范围 | 已观察 / 已确认采用 / 待确认建议，及适用端和页面 |
| 批准依据 | 用户确认或项目认可依据；未确认写未确认，不编日期与批准人 |
| 验证情况 | 源码提取、浏览器检查分别说明，未运行写 Not run |

## 设计原则

用少量具体原则说明设计意图、信息密度、交互反馈及优先级，不照搬参考品牌的宣传文字。

## 快速摘要

只列影响决策的核心约束和主题特征；参数查通用规范，组件用法查组件文件，避免重复维护数值。

## 规范导航

按实际文件建立相对链接：通用规范、组件、页面模式、品牌资产。不创建的文件不链接；无 LOGO 时写“未提供，不生成正式标识”。

## 缺口与冲突处理

列影响采用的缺口、多套实现冲突及其范围；待确认建议不能用于审核扣分。已确认规则变化先批准，不因源码更新自动迁移。生成和审核读取同一版本及采用范围。
