# 示例走查：简化项目创建

此文件是教学用的虚构需求依据，不是线上功能、真实用户批准记录或正式需求副本。打开 [example.html](../skills/pmspec-apply/assets/example.html) 即可离线操作；[template.html](../skills/pmspec-apply/assets/template.html) 是最小起步骨架，不是完整业务原型。

## 四个技能如何衔接

1. Explore：讨论“谁为什么需要创建项目”，确定本次只演示名称输入、保存与返回，不做成员、权限和真实存储。推荐 `simplify-project-creation`，在对话中确认共识。
2. Propose：用户批准后，写入目标产品 workspace 的 `pmspec/changes/simplify-project-creation/proposal.md`，以 Why / What Changes / Capabilities / Impact 为骨架。只写最终需求，不写“讨论后取消成员功能”。
3. Apply：确认 proposal 获批后，制作原型，实测并独立审核。当前随库 HTML 演示该阶段的结构和本地模拟，不是通过命令自动生成的真实产品需求。
4. Review：当前仅提示未启用，不生成报告或通过结论。

## 示例交互契约

```text
01 列表 ──新建──> 02 弹窗 ──保存成功──> 01 列表
  │                   │                    │
  │                   ├──校验失败：保留输入 │
  │                   ├──模拟失败：保留输入 │
  │                   └──取消/关闭：清空───>│
  └──查看详情──> 03 详情 ──返回───────────>│
```

上图是产品跳转关系；原型为方便评审将 01、02、03 同时平铺，点击链接滚到对应图示，并不隐藏其他独立画面。

- 列表“默认 / 空态”为轻量展示子 Tab。支持点击、左右键、Home/End 切换；只是评审状态，不会删除数据。
- 新建弹窗初始就独立可见；其底层为静态列表示意，不参与项目名称同步。
- 名称去首尾空格后为 1–20 个 Unicode 码点。空值、21 个字符拒绝，输入保留；1 个及 20 个字符允许。
- 弹窗外“评审模拟结果”选择成功或失败，不属于产品功能。失败保留输入；改回成功可重试。
- 成功后同步列表与详情的项目名称，切回列表默认态，显示模拟保存提示并前往列表。
- 取消/关闭不保存，清空输入并前往列表；平铺弹窗图仍保留用于评审。
- 详情页与列表共享演示项目名，刷新全部恢复初始示例。无真实业务请求或存储。

## 走查顺序

1. 确认三个独立图示及各自索引、功能概览一一对应。
2. 点击和键盘切列表子 Tab，确认只改变当前列表轻量状态，弹窗和详情仍可见。
3. 从列表进入新建图，试空值、超长名称和边界长度。
4. 选择失败并保存，确认提示、输入保留及重试。
5. 选择成功并保存，核对列表、详情同步和返回路径。
6. 测试取消与关闭不保存，再测详情返回。
7. 离线打开检查外部资源、控制台错误及主要内容遮挡。

以上是示例验收步骤，不表示已经执行；实际执行结果见 [验证记录](verification.md)。
